朗读桥 · 怎么用
=====================================

【它是两部分，缺一不可】

  1. DSH 插件 dsh-tts-bridge  —— 住在 DSH 里，负责把会话里的话排成队
  2. 浏览器扩展「朗读桥」      —— 住在浏览器里，负责真的去点 DeepSeek 的朗读

  （插件那一半负责「知道说了什么」，扩展那一半负责「让声音出来」）


【一、装 DSH 插件】

  它已经在 DSH 的插件市场里了 —— 打开市场搜「朗读桥」装上就行。
  用命令行装也可以：

    dsh plugin --profile web add github:Yuuyuko-uu/dsh-tts-bridge

  （这个插件没有发到 npm 上，所以要写 github: 那一种；
    写成 add dsh-tts-bridge 会找不到包。）

  装完重启一次 DSH。


【二、装浏览器扩展】

  1. 打开 chrome://extensions   （Edge 用 edge://extensions）
  2. 打开右上角（Edge 是左下角）的「开发者模式」
  3. 点「加载已解压的扩展程序」，选这个文件夹
  4. 打开 https://chat.deepseek.com 并登录你自己的账号
  5. 这个页面左下角会出现一行状态字，就装好了

  只支持 Chromium 内核的浏览器（Chrome / Edge / Brave 等）。
  Firefox 不行，它的扩展机制是另一套。


【三、第一次先自己点一下朗读（必做）】

  浏览器不信任「程序点的按钮」，只信任真人点的。所以第一次用之前：

  1. 在 DeepSeek 那个页面里，用鼠标点一下它自己的「朗读」按钮
  2. 之后就一直能出声了（自动念、点我们的 ▶，都不用再点）

  （这是浏览器定的规矩，绕不过去。哪天又不出声了，再真点一下就好。）


【四、怎么用】

  · 每条回复下面三个键：
      ▶ 朗读（用 DeepSeek 的声音念这一条）
      ⏸ 停止
      ♡ 收藏

  · DSH 窗口右下角那张小卡片 🐳 朗读桥：
      ⏸ 停止    一键停 —— 不管声音是从哪儿念出来的
      听谁 ▾    勾选要听哪些对话（默认一个都不听，自己勾）
      收藏 ▾    分区收藏：点句子重念、⇄ 换分区、✕ 删掉
      导出      分区列表最下面，导出成 markdown

  · 按住状态行 0.6 秒 = 开关「自动朗读」
  · 卡片整张按住就能拖，位置记得住


【五、数据在哪】

  DSH 的 .dsh\tts-bridge.json —— 「听谁」和「收藏」都在里面，重启不丢。


【六、出问题先看这三条】

  1. 没声音      → 在页面里真点一下朗读
  2. 卡片不见了  → DSH 插件没跑起来，重启 DSH
  3. 卡住了      → 把 DeepSeek 那个页面按 F5
